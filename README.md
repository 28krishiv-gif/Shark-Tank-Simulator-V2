# Shark Tank Simulator V2 🦈

## About
Shark Tank Simulator is an interactive investment simulation
where players analyze fictional businesses and decide whether
to invest in them.

## How It Works
Players:
- Analyze business fundamentals
- Examine historical growth
- Rate financial information
- Decide whether to invest
- Accept or negotiate investment deals
- See the company's simulated performance over five years
- Compare their analysis with the game's assessment

## Technologies
- Python
- Streamlit
- Pandas
- Matplotlib

## Features
- Three difficulty levels
- Randomly generated business data
- Investment negotiation
- Five-year business simulation
- Financial data visualization
- Player analysis and feedback
- Running net return
- Post-game company comparison

## How to Run
Click the link and then press play.

## Why I Built This
I wanted to combine my interests in data science, economics, and computer science.

I originally intended this project to be a simple conclusion to learning Python over the summer. Instead, I decided to use it as a way to internalize, apply, and combine what I had learned during previous school years.

Each version of the game represents the knowledge and skills I gained during the previous year.
